## 关于 Rocky Blog

这里是 Rocky 的个人博客，用来记录技术笔记、工程实践、工具折腾与生活随笔。

### 站点说明

- 仓库地址：[RockyBabcock/rocky-blog](https://github.com/RockyBabcock/rocky-blog)
- 基于 [Astro](https://astro.build/)、React 与 Tailwind CSS 构建；部分设计与实现参考了 [astro-koharu](https://github.com/cosZone/astro-koharu)（AGPL-3.0）。
- 支持中文、英语、日语和法语界面，以及全文搜索与本地阅读偏好设置。
