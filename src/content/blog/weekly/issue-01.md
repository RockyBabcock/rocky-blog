## 本周值得关注

### 1. Astro 7 内容层加载器

通过统一的 Content Layer Loader，Markdown 与外部数据源都可以共享同一套类型安全的 Schema 校验机制，构建速度与开发体验同步提升。

### 2. 纯 CSS 变量的主题系统

不再需要庞大的运行时样式库，用标准 CSS 自定义属性即可在浅色与深色模式之间毫秒切换，零水合负担。

### 3. 一句摘录

> 简洁不是删去所有装饰，而是让留下的每一处细节都有存在的理由。
